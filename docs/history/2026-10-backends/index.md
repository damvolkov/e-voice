# 2026-10 · Backends benchmark

Second round, after adding Canary, Cohere, Whisper, Kroko, language identification, GTCRN denoising and
emotion2vec+ large. Same machine and method as [the first round](../2026-10-benchmark.md):

- 32 cores, CPU only, onnxruntime 1.28.2 through sherpa-onnx 1.13.8, intra-op spinning off;
- FLEURS es/en (200 utterances each), CREMA-D en (400), MESD es (129);
- `file`: the upload path, 4 concurrent items;
- `live1` / `live4`: utterances paced in real time over the live intake, 1 or 4 streams. The first
  round paced 12 utterances, this one 20.

Annex files, generated by `make annex OUT=docs/history/2026-10-backends` from the raw results in
`data/stt/ops/results`:

- [`report.md`](report.md) — every metric of every run;
- [`summary.csv`](summary.csv) — the same, machine-readable;
- [`charts.md`](charts.md) — the charts below.

## ASR

| Engine | WER es | WER en | CPU s / audio s | Throughput | Live final p50 / p95 | Peak RSS |
|---|---|---|---|---|---|---|
| Parakeet TDT v3 | **4.5 %** | 8.1 % | 0.25 | 25× | 760 / 1020 ms | 2.8 GB |
| Whisper large-v3 turbo | 4.9 % | **5.6 %** | 1.68 | 7× | 2140 / 2800 ms | 4.5 GB |
| Cohere Transcribe | 6.0 % | 6.6 % | 0.95 | 12× | 1300 / 1950 ms | 5.9 GB |
| Canary 180M flash | 7.4 % | 8.5 % | 0.41 | 20× | 880 / 1040 ms | 2.0 GB |
| Canary + Whisper-tiny LID | 7.5 % | 8.5 % | 0.43 | 20× | 970 / 1060 ms | 2.6 GB |
| Nemotron 3.5 1120 ms | 8.4 % | 11.4 % | 0.41 | 21× | 740 / 1020 ms | 2.1 GB |
| Kroko (streaming) | 8.7 % | 12.7 % | **0.17** | **27×** | **690** / 1000 ms | **1.6 GB** |

- **Parakeet stays the file default.** It is the most accurate in Spanish and the cheapest accurate
  engine.
- **Whisper turbo is the English ceiling** (5.6 % against 8.1 %), at 6.6× Parakeet's CPU and over 2 s
  per final live. Use it as a request-selectable choice for files, not for live.
- **Cohere** is second in both languages but the heaviest in memory. Even accent-folded it trails
  Parakeet in Spanish (5.5 % against 4.3 %).
- **Canary** beats no engine on accuracy. Its niche is es↔en translation (not exposed yet) and a
  smaller memory footprint.
- **LID** identified every FLEURS utterance correctly (Canary's WER is unchanged). It costs about
  90 ms per final and 0.5 GB.
- **Kroko** is the cheapest streaming engine and the lowest live latency, close to Nemotron in
  Spanish and worse in English. It is CC-BY-SA, intended for hobby and research: it stays measured, not
  shipped as a default.

## Front end

| Change | Effect |
|---|---|
| GTCRN denoising | es 8.4 → 8.9 %, en 11.4 → 13.0 % on clean FLEURS; finals live unchanged (700 ms). It helps only with noise, which this benchmark does not contain, so it stays off by default. |

## SER

| Model | CREMA-D accuracy | macro-F1 | angry recall | MESD accuracy | CPU s / audio s |
|---|---|---|---|---|---|
| emotion2vec+ base | 65.8 % | 0.65 | **87.7 %** | **24.8 %** | 0.27 |
| emotion2vec+ large | **73.8 %** | **0.74** | 80.0 % | 20.2 % | 0.34 |

- **large** gains 8 points of accuracy and 0.09 F1 on English sentences, for +27 % CPU and +0.4 GB.
  It loses angry recall and is no better on MESD.
- MESD (acted single words) remains unrepresentative of Spanish speech. No openly licensed
  sentence-level Spanish set exists: MEACorpus needs its audio rebuilt from YouTube, and EMOVOME and
  EmoMatchSpanishDB need signed agreements.
- **base stays the default.** large is the choice for English-first deployments that value overall
  accuracy over catching anger.

## Defaults after this round

| Node | Default | Why |
|---|---|---|
| asr live | Nemotron 1120 ms | streaming partials at the best accuracy among commercially usable streaming models |
| asr files | Parakeet | best es, cheapest accurate; Whisper/Cohere available through `offline.choices` |
| lid | off | Parakeet and Whisper detect the language themselves; enable it with Canary or Cohere |
| denoise | off | costs accuracy on clean speech |
| ser | emotion2vec+ base | higher angry recall, cheaper; large selectable |
